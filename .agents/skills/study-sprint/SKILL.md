# Skill: Capacity-Aware Study Sprint

Use this skill when building the 30-day interview sprint or Day 31+ planning.

1. Read `docs/18_FIRST_30_DAY_INTERVIEW_SPRINT.md` and `docs/09_PHASE_2_LEARNING_AND_PLANNING.md`.
2. Ask for start date, target-role focus and available daily minutes in one setup flow.
3. Generate a preview; never create tasks before explicit acceptance.
4. Include Grind 75 DSA tasks, skill-bank questions, due revisions and review checkpoints.
5. Calculate workload from estimated minutes. Warn and offer 30/45/60-day options when the 30-day plan does not fit.
6. Never silently exceed available minutes, erase deferred tasks or infer completed questions.
7. Preserve official Grind 75 source order and deduplicate by normalized URL/slug.
8. Day 31+ uses the visible weighted priority model, explains reasons, and creates rolling plans only after acceptance.
9. Use deterministic code for all date/time/capacity/priority calculations; do not call AI for arithmetic.
10. Test timezones, day boundaries, capacity limits, rescheduling and plan regeneration.
